  cd webapp

================================================================================
TROUBLESHOOTING QUICK REFERENCE
================================================================================

Connection Refused?
  → Check Django is running: python manage.py runserver 0.0.0.0:8000

CORS Error?
  → Check: CORS_ALLOW_ALL_ORIGINS = True in webapp/webapp/settings.py

Invalid Credentials?
  → Create test users (see ENVIRONMENT_SETUP.md)

API Returns 404?
  → Verify URL routes in webapp/accounts/urls.py

JSON Parse Error?
  → Test with browser: http://localhost:8000/accounts/api/login/

Request Timeout?
  → Check network connection
  → Django server might be slow
